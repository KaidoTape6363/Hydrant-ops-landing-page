ABOUT

A spreadsheet can't tell you a photo is missing

Hydrant Ops exists because the old process — Google Sheets, a shared drive full of defect photos, no real access control — worked right up until it didn't.

What came before

Station 44's Rota 2 ran hydrant testing through a Google Sheet and a Google Apps Script backend — functional, but with no real way to stop someone leaving a required field blank, no enforcement that a defect actually had photo evidence, and no clean way to separate what three different Rotas were each responsible for.

What had to change

The fix wasn't "digitize the spreadsheet" — it was building something that understood the actual shape of a fire station's duty: a 3-Rota rotation, PIN-gated field access instead of individual logins for Section Commanders, and defect evidence that's structurally impossible to skip.

HOW IT GREW

From one Rota's fix to a station-wide tool

Early build

A Google Sheets + Apps Script backend

The original version — functional, but every rule had to be manually followed rather than enforced. A missing photo or a skipped field was a human error waiting to happen, not something the system caught.

Migration

Moved to a real backend

Rebuilt on Supabase — Postgres, real authentication, and Storage for defect photos — so the rules that used to live in someone's head (two photos per defect, PIN access per Rota, who can see what) became enforced by the system itself.

Hardening

Fixed for real field conditions

Timezone bugs that hid hydrants from the field at the wrong hour. Data import issues from real inspection records with typo'd appliance codes. A Test Mode built specifically so an IC could try new features without ever risking a real duty's data.

Now

Built to scale past one station

What started as Rota 2's own fix is structured to support all 23 of Singapore's fire stations — appliance codes read from each station's own data instead of assumed, indexes in place for the row counts that come with scaling, and a defect lifecycle that tracks rectification all the way through reinspection.

A NOTE ON WHAT THIS IS

Hydrant Ops is a tool built by station personnel, for station personnel — it is not an official SCDF system, and it isn't sold or distributed outside the people who use it day to day. Every feature on this site came from a real gap in a real duty, not a product roadmap.
